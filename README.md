# budget-tracker — מעקב הכנסות והוצאות

אפליקציה אישית לניהול הכנסות והוצאות, בנויה עם React + Vite ועוצבה עם [Tamagui](https://tamagui.dev).

## הרצה

```bash
npm install
npm run dev
```

## מה יש באפליקציה

- סרגל צד עם שלושה עמודים: **פרופיל**, **לוח בקרה** ו**תנועות קבועות** (בטלפון הוא נפתח מכפתור ☰)
- לוח בקרה: סיכום חודשי (הכנסות, הוצאות ויתרה), גרף מגמה ורשימת התנועות של החודש הנבחר
- הוספת הכנסה או הוצאה עם סכום, תאריך, תיאור וקטגוריה
- **תנועות קבועות**: הכנסה או הוצאה שחוזרת כל חודש באותו סכום, יום בחודש, תיאור וקטגוריה.
  אפשר להוסיף, לערוך, להפסיק (ההיסטוריה נשמרת) ולמחוק. יום שלא קיים בחודש (למשל 31 בפברואר) נרשם ביום האחרון של החודש.
- הנתונים נשמרים בדפדפן (localStorage) ומסונכרנים לקובץ `Budget Tracker/budget-data.json` ב-Google Drive

## איך נשמרות תנועות קבועות

בקובץ ב-Drive (גרסה 2) נשמרת רק ההגדרה של כל תנועה קבועה, במערך `cyclic`:

```json
{ "id": "…", "type": "expense", "amount": 4800, "description": "שכר דירה", "category": "דיור",
  "dayOfMonth": 1, "startMonth": "2026-07", "endMonth": null }
```

התנועות החודשיות עצמן לא נשמרות – הן נוצרות מההגדרות (`src/cyclic.js`) רק כשמציגים אותן בלוח הבקרה.

## מבנה

- `src/App.jsx` — מצב האפליקציה, ניווט בין העמודים והפריסה (סרגל צד)
- `src/pages/` — עמודי פרופיל, לוח בקרה ותנועות קבועות
- `src/components/` — רכיבי ממשק משותפים
- `src/cyclic.js` — יצירת התנועות החודשיות מהגדרות התנועות הקבועות
- `src/useCloudSync.js`, `src/google/` — סנכרון ל-Google Drive
- `src/tamagui.config.js` — הגדרות Tamagui (ערכת עיצוב v6)
- `vite.config.js` — מפנה את `react-native` ל-`react-native-web`, ש-Tamagui צריך בדפדפן
